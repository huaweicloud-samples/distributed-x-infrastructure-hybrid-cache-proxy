## 组件说明

### 1. 缓存代理层 (CCE)

| 端口 | 用途 | 说明 |
|------|------|------|
| 80 | HTTP 代理 | 全量缓存 + 范围优化 |
| 3129 | TLS 代理 | 加密传输 |
| 8080 | 健康检查 | 存活探针 |
| 8081 | 监控面板 | Prometheus 指标 |
| 9090 | 指标采集 | 暴露 Prometheus 端点 |

### 2. 缓存策略

| 层级 | 介质 | 淘汰策略 |
|------|------|----------|
| L1 | RAM 内存 | LRU |
| L2 | SFS 文件存储 | LRU/TinyLFU |
| L3 | OBS 对象存储 | TTL |

### 3. 数据流

1. 客户端发起对象存储请求
2. 代理检查 RAM 缓存
3. RAM 未命中 → 检查 SFS 缓存
4. SFS 未命中 → 回源 OBS
5. 逐级缓存数据

---

## 安全考虑

- TLS 加密客户端到代理的流量
- IAM 鉴权保持一致
- 缓存 TTL 控制敏感数据暴露时间

---

## 高可用设计

- 无状态代理支持水平扩展
- 多节点部署共享 SFS 存储
- DNS 轮询实现负载均衡
