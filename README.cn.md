## 简介

本项目是高性能对象存储混合缓存代理的华为云实现，旨在展示如何利用华为云的对象存储和容器服务构建低延迟、高吞吐的数据访问加速方案。该方案与参照架构同构落地，充分利用华为云 OBS、SFS、CCE 等服务的强大能力，为开发者提供一套完整的云原生缓存加速参考实现。

### 核心功能

本解决方案包含以下核心能力：

1. **智能多层缓存** - RAM 缓存 + 文件存储缓存 + OBS 后端的三级缓存架构，显著降低访问延迟
2. **透明认证复用** - 无需缓存凭证，复用客户端请求签名，保持与 IAM 策略的一致性
3. **共享文件存储** - 多缓存节点通过 SFS 共享缓存数据，消除冗余的数据拉取
4. **无状态代理设计** - 支持水平扩展的高可用部署架构
5. **内容感知压缩** - LZ4 压缩可将存储占用压缩至 1/2-1/10

### 适用场景

本项目适用于以下场景：需要降低对象存储访问延迟的混合云应用、医疗影像和基因数据等大规模数据访问、量化交易的低延迟数据获取、以及自动驾驶领域的高频数据访问场景。

## 使用方法

### 配置缓存代理

编辑配置文件：

```yaml
server:
  mode: "proxy_only"
  proxy_port: 3128
cache:
  cache_dir: "/cache"
  max_cache_size: 524288000  # 500 MB
object_storage:
  endpoint: "https://obs.cn-north-4.myhuaweicloud.com"
  region: "cn-north-4"
```

### 使用代理

```bash
# 设置 HTTP 代理
export HTTP_PROXY=http://<proxy-ip>:3128

# 使用 obsutil 访问 OBS
obsutil cp obs://your-bucket/key ./local
```

## 详细说明

### 缓存策略

- **写穿式缓存**: 上传后对象立即可用于缓存读取
- **RAM 缓存**: 热数据加速访问
- **范围请求优化**: 部分缓存命中时仅获取缺失字节
- **LRU 淘汰**: 自动清理冷数据

### 性能优化

- 多级缓存减少 OBS 请求
- 压缩降低存储占用
- 共享存储支持水平扩展
